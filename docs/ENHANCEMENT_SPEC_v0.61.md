# EasyDanceStudio v0.61 변경 명세

기준 빌드 `v0.6` · 착수 범위 초안

이번 버전의 목표는 **마우스로 원하는 구도를 빠르게 잡고, 화면에서 고른 부분만 보정해 그대로 출력하는 것**이다. 기준 기능과 기존 요구사항은 [이전 명세](ENHANCEMENT_SPEC_v0.5.md)를 참조한다.

## 1. 뷰포트 카메라

코이카츠·허니 셀렉트에서 익숙한 마우스 동작을 전체 창 뷰포트에 적용한다. 첫 구현의 드래그 방향은 아래와 같이 제안한다.

| 입력 | 동작 |
|---|---|
| 짧은 좌클릭 | 모델을 선택하고, 빈 곳이면 선택을 해제한다. |
| 좌클릭 드래그 | 현재 회전 중심을 기준으로 상하좌우 회전한다. |
| 우클릭 드래그 | 마우스를 위로 밀면 확대하고 아래로 당기면 축소한다. 가로 이동은 무시한다. 시야각은 그대로 두고 카메라 거리를 바꾼다. |
| 휠 버튼 드래그 또는 `Shift` + 우클릭 드래그 | 화면을 상하좌우로 이동한다. |
| 휠 스크롤 | 커서 아래 보이는 모델 표면을 기준으로 확대·축소한다. 표면이 없으면 현재 회전 중심을 사용한다. |

- **선택과 회전 구분.** 좌클릭을 누른 위치에서 기존 5픽셀 기준 이내로 놓으면 선택한다. 기준을 넘으면 회전으로 확정하며, 놓을 때 선택을 바꾸지 않는다. 회전 중인 모델과 현재 선택이 유지되어야 한다.
- **조작 우선순위.** 기즈모 핸들에서 시작한 좌클릭은 기즈모가 처리한다. 카드·탭·대화상자 위에서 시작한 입력은 카메라를 움직이지 않는다. 뷰포트에서 시작한 드래그는 카드 위를 지나도 계속된다. 버튼 해제, 창 포커스 상실, 대화상자 표시, 로딩 시작 시 드래그를 끝낸다.
- **카메라 VMD에서 수동 전환.** 실제 회전·이동·확대가 시작될 때 수동으로 전환한다. 버튼을 눌렀다 놓거나 모델을 선택하는 것만으로는 전환하지 않는다. 전환 첫 프레임의 위치·방향·시야각이 튀지 않아야 한다. VMD의 화면 기울기를 그대로 이어갈 수 있는지도 확인한다.
- **커서 기준 확대.** 휠 입력으로 확대하는 동안 기준점이 가능한 한 같은 화면 위치에 남아야 한다. 표면 탐색과 보정 때문에 재생이나 입력이 눈에 띄게 밀리는지 Windows Player에서 확인한다. `F`와 전체 보기로 회전 중심을 다시 잡을 수 있다.

## 2. 대상을 골라 화면 보정

캐릭터 또는 무대를 선택하면 속성 창에서 대상의 색과 밝기를 조정할 수 있다. 캐릭터는 실제 PMX 재질 목록에서 한 항목을 골라 **색과 광택**을 따로 조정할 수 있어야 한다. 첫 버전은 기존 툰·PBR 경로가 지원하는 조정값부터 연결한다. 지원 여부와 현재 적용 상태를 속성 창에 표시한다.

- **기본 흐름.** 재생 중 원하는 장면에서 멈춘다 → 카메라로 보정할 곳에 접근한다 → 대상이나 재질을 고른다 → 화면을 보며 값을 바꾼다 → 전후를 비교한다.
- **비교·초기화.** 같은 카메라와 같은 프레임에서 v0.61 보정 적용 전후를 한 버튼으로 비교한다. 선택한 재질의 보정만 초기화할 수 있고, 확정한 변경은 실행 취소할 수 있다.
- **저장·출력.** 원본 PMX와 텍스처 파일은 수정하지 않는다. 보정값은 장면에 저장하고 재실행 후 복원한다. 미리보기와 기존 PNG·MP4 출력에서 같은 보정값을 사용한다. 재질을 안정적으로 식별할 수 없을 때는 다른 재질에 적용하지 않고 이유를 표시한다.
- **조작 화면.** 전체 창 뷰포트와 접히는 패널을 유지한다. 대상 선택과 기본 조작을 먼저 노출하고 재질별 설정은 필요할 때 펼친다. 이번 범위의 새 UI로 노드 편집기나 프리셋 관리 화면을 추가하지 않는다.

## 3. 작업 순서와 완료 기준

1. **마우스 카메라부터 구현한다.** Windows Player에서 짧은 클릭과 드래그의 경계, 기즈모, 대화상자, 패널을 가로지르는 드래그, 카메라 VMD의 수동 전환을 확인한다. 전신에서 얼굴 근처까지 이동하면서 확대 방향과 감도를 직접 확인한다. 기존 입력 프로브에는 선택·회전·확대 충돌에 대한 회귀 검사를 넣는다.
2. **재질 하나의 보정 흐름을 연결한다.** 같은 포즈에서 피부나 의상 재질 하나를 바꿨을 때 주변 재질은 그대로인지 확인한다. 전후 비교, 초기화, 실행 취소, 저장·재열기를 거쳐 같은 결과가 나와야 한다.
3. **같은 프레임을 출력해 비교한다.** 캐릭터·무대가 있는 테스트 장면에서 보정 전후와 미리보기·출력의 같은 프레임을 기록한다. 기본 재생 중 카메라 조작이 밀리지 않는지 확인하고, 사용한 PC·해상도·모델과 문제를 남긴다.

v0.61의 완료 기준은 **마우스로 원하는 곳에 접근하고, 재질 하나를 찾아 손본 다음, 재실행과 출력에서도 그 결과를 얻는 것**이다. 렌더러 교체, 노드 합성, 대규모 프리셋 추가, 배포 검증은 후속 범위로 둔다.
