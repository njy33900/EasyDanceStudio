# D-03 모션 맞춤 — 진단 구현과 보완·접지 조사

2026-11-22, Claude. 명세 0.5 D-03. (1) 진단은 구현·검증, (2) 런타임 보완과 (3) 접지 보정은 조사와 설계까지.

## 1. 진단 (구현)

- `Poc/MmdMotionFit.cs`, 인스펙터 모션 섹션의 "모션 맞춤 진단"(`MotionFitInfo`).
- VMD는 본·모프를 **일본어 이름**으로 지정한다. 모델에 없는 이름은 적용되지 않는다(UMT 변환 결과 `MmdMotionSummary.missingBones/missingMorphs`).
- 준표준 본은 증상과 함께 보여 준다.

  | 본 | 없을 때 보이는 증상 |
  |---|---|
  | 全ての親 | 전체 이동이 빠져 캐릭터가 제자리에 머묾 |
  | グルーブ | 몸 전체의 상하 움직임(점프·무릎 굽힘)이 빠짐 |
  | 腰 | 골반 회전이 빠짐 |
  | 上半身2 | 가슴 위쪽 비틀림이 빠져 상체가 뻣뻣해 보임 |
  | 足IK親 | 발 위치 이동이 빠져 발이 미끄러지거나 다른 곳을 디딤 |
  | 腕捩·手捩 | 팔·손목 비틀림이 빠져 꼬여 보임 |
  | 足D·ひざD·足首D | 다리 D본 움직임이 빠짐 |
  | 両目 | 두 눈을 함께 돌리는 시선이 빠짐 |

- 그 밖의 본은 "그 본의 움직임은 적용되지 않음"으로 묶는다.
- 모프는 입 모양(あいうえお 등)과 눈 표정(まばたき 등)을 따로 센다.
- 검증(UI 프로브 `motion_fit_diagnosis_in_user_words`): 준표준 본·없는 본·모프 키를 가진 VMD를 Shift-JIS 이름으로 만들어 연결한다. 그 뒤 모델에 실제로 없는 이름만 정확히 나열되는지 확인한다.

### 실제 모션 측정 (Whiplash `[SMOOTH].vmd`, 2026-11-22)

| 모델 | 모션이 쓰는 본 | 모델에 없는 본 | 없는 모프 | 모델에 없는 준표준 본 |
|---|---|---|---|---|
| Gene_light | 173 | 96 | 37 / 63 | 腰, 足D 계열 |
| Sandrone | 173 | 72 | 30 / 63 | 없음 |

- 없는 본의 대부분은 모션 작성자 모델에만 있는 본이다(머리카락·넥타이·소매·`インジケータ`·`操作中心`·`新規ボーン1`). 이런 본이 없어도 몸 동작에는 영향이 없다. 진단은 이들을 "그 밖의 본"으로 묶어 준표준 본과 구분한다.
- Gene은 `腰`가 없어 골반 회전이 빠지고, `足D`가 없어 다리 D본 키가 빠진다.
- `+右ひじ補助`, `右手捩1~3`, `腕捩1~3`은 작성자 모델의 확장 본이다. 표준 `腕捩`/`手捩`과는 다르다.
- VMD 이름 필드는 15바이트라서, 긴 이름은 Shift-JIS 문자 중간에서 잘린다(`右もみあげ１シ�`). 이런 이름은 모델 쪽 이름과 일치할 수 없으므로 원래 적용되지 않는다.

## 2. 런타임 보완 (조사·설계, 미구현)

목표는 PMX 파일을 바꾸지 않고, 메모리에 올린 모델에 준표준 본을 넣어 모션 키가 적용되게 하는 것이다.

| 본 | 정점 가중치 변경 | 넣는 방법 | 난이도 |
|---|---|---|---|
| 全ての親 | 없음 | 최상위 본의 부모로 삽입 | 낮음 |
| グルーブ | 없음 | `センター`와 그 자식 사이에 삽입 | 낮음 |
| 足IK親 | 없음 | `足ＩＫ`의 부모로 삽입 | 낮음 |
| 腰 | 없음(다리는 `腰キャンセル`로 상쇄) | `下半身`·`上半身`의 부모로 삽입, 다리 쪽에 회전 상쇄 본 추가 | 중간 |
| 上半身2 | **있음**(上半身 가중치 분할) | 상체 정점 가중치 재분배 | 높음 |
| 腕捩·手捩 | **있음**(팔 가중치 분할, 회전축 고정) | 가중치 재분배 + 축 제한 | 높음 |

- 위치: `MmdStagedPmxBuild`는 UMT가 계층을 만들기 **전에** 파싱된 `PMXModel`을 가지고 있으므로, 여기서 본 배열을 고칠 수 있다.
- **인덱스 문제**: 본을 중간에 넣으면 정점 가중치·IK 링크·모프·강체·표시 틀의 본 인덱스를 모두 다시 매겨야 한다. 그래서 **끝에 덧붙이고 부모 인덱스만 바꾸는 것**이 안전하다.
- **평가 순서**: MMD는 같은 변형 계층 안에서 인덱스 순으로 본을 계산한다. 끝에 붙인 부모(예: グルーブ)는 자식보다 인덱스가 크다. 그러면 자식이 부모보다 먼저 계산되므로, 덧붙인 본의 변형 계층을 낮추거나 UMT의 계산 순서를 확인해야 한다(`MMDTransformManager`).
- 제안 순서: 가중치가 필요 없는 4개(全ての親·グルーブ·足IK親·腰)를 P1 티켓으로 먼저 한다. 수용 기준: 준표준 본이 있는 모델(Sandrone)과 보완한 모델(Gene)에서 같은 VMD의 `センター`·발 위치 궤적을 비교한다. 上半身2·捩り는 가중치 재분배 연구가 필요해 후속으로 둔다.
- UMT 내부를 고쳐야 하면 `PATCHES.md`에 기록한다(ADR-017).

## 3. 접지 보정 (조사, 미구현)

- 원인: 모션의 `センター`·`足ＩＫ` 이동량은 원작자 모델의 다리 길이를 기준으로 한다. 다리 길이가 다른 모델에 적용하면 발이 미끄러지거나 바닥을 뚫는다.
- 방법 A — 보폭 맞춤(제안 1순위): 이동 성분(`センター`·`グルーブ`·`足ＩＫ`·`足IK親`·`全ての親` 위치)에 `대상 다리 길이 / 원본 다리 길이`를 곱한다. 원본 다리 길이는 VMD에 없다. 표준 모델 기준값을 쓰거나 사용자가 고르게 한다. 계산이 싸고 결정적이며 굽기 캐시와도 충돌하지 않는다.
- 방법 B — 접지 고정: 발 높이와 속도로 접지 구간을 찾고, 그 구간 동안 발 IK 목표를 고정한다. 결과는 좋지만 다리 IK 재계산과 물리 굽기 캐시 무효화가 따른다.
- 측정 지표(수용용): 접지 구간(발 높이가 최저 + 2 cm 이내이고 수직 속도가 작을 때)에서 발목의 **수평 이동 속도 평균**(cm/s)과 **바닥 관통 깊이 최대**(cm). 같은 VMD를 두 모델(Gene·Sandrone)에 적용해 보정 전후를 비교한다.

## 결정 대기

- 런타임 보완을 P1으로 착수할지(가중치 불필요 4개 본부터).
- 접지 보정 방식 A의 원본 다리 길이 기준값(표준 모델 값 vs 사용자 입력).
