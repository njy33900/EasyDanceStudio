## 6. 다음 작업: V0 전체 화면 뷰포트 (명세 v0.4 V0-01~06)

확정 사항(ADR-016): 3D가 창 전체, 패널은 떠 있는 흰 카드, 패널별·전체 숨김, `H` 전환, `H`/`Esc` 복원(대화상자 없을 때), 모서리 복원 버튼, 재실행 시 UI 보이는 상태로 시작, 표시 상태는 `.mmdscene`에 저장하지 않음.

### 현재 구조에서 출발점
- 레이아웃은 `MmdSceneWorkspace.Initialize()`에서 `eds-topbar` / `eds-body`(explorer · viewport-wrap · inspector) / `eds-playback` / `eds-statusbar` 순의 **flex 흐름**이다. 루트·본문은 투명해야 한다(칠하면 3D를 가림).
- 카메라 영역: `UpdateViewport()`가 뷰포트 카드의 `contentRect`를 `Camera.main.rect`로 바꾼다(`MmdSceneWorkspace.cs` 약 255줄). V0에서는 **항상 `new Rect(0,0,1,1)`**.
- 뷰포트 카드의 흰 테두리 여백과 둥근 모서리 마스크(`AddRoundedCorners`)는 V0에서 불필요 → 제거하거나 카드 대신 오버레이 컨테이너로.
- 3D 입력 차단은 `PointerOverUi()`(`panel.Pick`)와 `PointerInViewport()`(카메라 픽셀 rect ∩ 비-UI)로 이미 일반화돼 있다 → **패널을 숨기면(`display: none`) 그 자리는 자동으로 3D 입력이 된다.** 떠 있는 카드는 pickable이어야 한다.
- 기즈모 오버레이(`GizmoOverlay`)·모드 바·빈 장면 안내·조작 힌트는 지금 뷰포트 카드 자식이다 → 전체 화면 오버레이 레이어로 옮긴다.

### 구현 제안
1. **레이어 구조:** 루트(투명, picking ignore) 아래에 `Overlay3D`(기즈모·힌트·빈 장면 안내, ignore) + 카드들(absolute 배치: 상단 바 top, 탐색기 left, 속성 right, 재생 바 bottom; 여백 12px, 둥근 12px, 흰 배경, 얇은 테두리/그림자) + 상태 줄(재생 바에 합치거나 하단 얇은 카드).
2. **표시 상태:** `ShowPanel(name, bool)`, `FocusView` 토글. 상단 바 오른쪽에 "보기" 아이콘 메뉴(패널별 토글) 추가. 숨김 중 진행 중인 기즈모/카메라 드래그는 `CancelPointerDrag()`로 종료. 필수 메시지(대화상자, 오류)는 집중 보기에서도 표시(대화상자 오버레이는 이미 최상위).
3. **단축키:** `ProcessViewportInput`의 `!textFocused` 분기에 `H`(전환), 숨김 상태 + 대화상자 없음일 때 `Esc` 복원. `ReadDevices`에 키 추가. `H`는 Ctrl 조합일 때 무시.
4. **프레이밍 안전 영역(V0-05):** `View.Frame()`이 보이는 카드가 덮지 않는 사각형에 맞추도록. 방법 후보: (a) 안전 영역 중심으로 투영 중심을 옮기는 off-center 투영(`camera.projectionMatrix` 직접 설정, FOV 변경 시 재계산, `ScreenPointToRay`는 이를 따른다) 또는 `usePhysicalProperties` + `lensShift`; (b) 간단히 안전 영역 비율로 거리·피벗을 보정. (a)가 패널 토글 시 시점이 튀지 않아 명세에 맞다. 피킹·기즈모 투영은 같은 카메라를 쓰므로 자동으로 맞는다.
5. **DPI(V0-06):** `PanelSettings`는 `ScaleWithScreenSize`(1280×720 기준)만 쓴다. 150% 배율에서 측정해 필요하면 `Screen.dpi`를 반영한 배율 규칙 결정.

### 검사 영향 (PocSceneUiProbe)
- `viewport_excludes_sidebars`(카메라 rect가 사이드바를 제외)는 V0에서 의미가 바뀐다 → "카메라 rect = 전체, 보이는 카드 위는 UI, 숨긴 카드 자리는 3D" 검사로 교체.
- `viewport_pick_distinguishes_panels_and_viewport`의 `topEdge`(툴바 바로 아래 3px)와 사이드바 점, 피킹 검사의 빈 공간 모서리·바닥 점 선택 로직은 카드 위치에 따라 다시 잡아야 한다(카드 영역은 `PointerOverUi`로 걸러짐).
- 추가할 검사 예: 패널별 숨김/표시 후 그 자리 클릭이 3D 선택으로 가는지, 집중 보기 전체 숨김 후 카메라 조작·복원 키·복원 버튼, 숨김 중 드래그 취소, 프레이밍 결과가 안전 영역 안에 투영되는지, 1280×720/1600×900에서 경계, 표시 상태가 재실행 시 기본값.
- 스크린샷: 패널 표시 / 집중 보기 각각 앱 자체 캡처로 확인.
