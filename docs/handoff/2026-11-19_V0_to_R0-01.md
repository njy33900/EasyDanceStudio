## 끝낸 일

직전 R0-02a의 누락 참조 보존 코드·검증은 그대로 유지했다. 그 위에 V0 전체 창 뷰포트와 떠 있는 UI를 구현했다.

- 카메라 `rect=(0,0,1,1)`, 카드형 상단/좌측/우측/하단 UI, 기존 흰 바탕 미니멀 시각 언어 유지.
- 상단 **보기** 메뉴로 상단 바·탐색기·속성 창·재생 바·기즈모 모드 바를 개별 숨김/복원. `H` 집중 보기 전환, `H`/`Esc` 또는 모서리 `UI` 버튼으로 복원. 집중 보기에서는 선택 강조와 기즈모 오버레이도 숨김. 재실행 시 전부 표시; `.mmdscene` 스키마에 표시 상태를 넣지 않음.
- 후속 요청으로 상단 바·탐색기·속성 창·재생 바·상태 바·기즈모 모드 바 각각에 `−` 숨김 버튼을 추가했다. **보기** 메뉴에 상태 바 항목도 추가했으며 숨긴 창은 메뉴에서 다시 켠다. 상단 바는 모서리 `UI` 버튼으로 복원한다.
- 이어서 숨긴 탐색기·속성 창·재생 바·상태 바·기즈모 바 자리에 짧은 가장자리 탭을 남겨 바로 복원하도록 했다. 상단 바를 숨기면 모서리 버튼이 `도구 모음 ▾`로 표시된다. 집중 보기에서는 접힌 탭을 숨기고 `UI` 버튼만 남긴다.
- 보이는 카드만 3D 입력을 차단, 숨긴 자리로 입력 전달. 진행 중 드래그를 표시 전환 시 종료. 대화상자 입력 우선순위 유지. 집중 보기 중 오류/로딩/저장 알림 표시.
- `FrameInRect`가 현재 보이는 카드 사이의 안전 사각형으로 프레이밍. 카드 표시 전환만으로 시점 변경 없음. 창 크기 1280×720/1600×900 자동 검사.
- 출력 프로필 `V0-<Mono|IL2CPP>`로 분리. 세부 구현과 제한: `docs/V0_VIEWPORT_LAYOUT.md`.
- 사용자 실행 혼란을 해결하기 위해 V0 Player는 옵션 없이 더블클릭하면 새 장면 UI를 기본으로 연다. `-legacyWorkspace`/진단 프로브 옵션은 이전 단일 모델 경로를 유지한다. `PocSmoke.cs`와 `Start-MmdPoc.ps1` 수정.

주요 변경: `MmdSceneWorkspace.cs`, 신규 `MmdSceneWorkspace.ViewportLayout.cs`(+`.meta`), `MmdSceneWorkspace.Gizmo.cs`, `MmdViewportCamera.cs`, `Resources/StudioTheme.uss`, `PocSceneUiProbe.cs`, 세 PowerShell 실행 스크립트와 `scripts/bash/` 프로필. 문서 `V0_VIEWPORT_LAYOUT.md`, `TASKS.md`, `BUILD_OUTPUTS.md`, `CHANGELOG.md`, `README.md`.
