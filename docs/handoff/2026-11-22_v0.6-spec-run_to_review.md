## 알게 된 것 (중요)

- 모델은 lilToon이 없어 **URP Unlit 대체 셰이더**로 그려진다. 조명은 툰·PBR 스타일에서만 보인다.
- **툰 셰이더에 쓰지 않는 두 번째 텍스처를 두면, 툰 재질이 남은 채 종료할 때 D3D12Core.dll이 크래시**한다(보고서는 통과해서 이전 검증으로는 안 보였음). 지금은 램프 색을 CPU에서 읽는다. verify-all에 "player exits"를 추가했다.
- MP4 디코드 비교로 검사 함수의 상하 반전 버그를 찾았다(인코딩은 정상). 출력 영상을 다시 읽어 렌더와 비교하는 검사를 유지할 것.
- Mono는 float 연산을 double 정밀도로 할 수 있다. float 시간으로 키를 고르는 코드는 경계에서 백엔드마다 달라진다. 새 코드는 double 시간 + 정수 프레임 맞춤을 쓴다.
- 네이티브 플러그인 `EdsMedia.dll`은 `scripts/build-native-media.bat`로 다시 빌드한다(VS 2026 C++ 도구, 정적 CRT). 소스는 `MMDStudio/Native/EdsMedia`.
