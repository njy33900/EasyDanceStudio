## 알게 된 것

- 모델·배경은 lilToon이 프로젝트에 없어 **URP Unlit 대체 셰이더**로 그려진다 → 조명 색·세기가 모델에 안 보이고, SSAO도 기본(DepthNormals) 설정으로는 거의 안 보였다. H2b에서 조명을 받는 툰 셰이더가 필요하다.
- Mono는 float 연산을 double 정밀도로 할 때가 있어, float 시간으로 키를 고르는 코드(레거시 `MmdPocCamera`)는 컷 경계에서 백엔드마다 결과가 갈린다. 새 코드는 double 시간 + 정수 프레임 맞춤.
- Whiplash 폴더에 실제 카메라 VMD 4종과 `aespa - Whiplash.wav`가 있다(Git 밖) — D-01 박자 추정에 쓸 수 있다.
