# Easy Dance Studio 사용자 매뉴얼

2026-11-22 기준 (v0.6)

## 1. 시작하기

Easy Dance Studio는 MMD 모델(PMX)과 모션(VMD)으로 춤 장면을 꾸미고 PNG·MP4로 내보내는 Windows 앱이다. 원본 PMX·VMD·WAV는 복사하거나 고치지 않고, 장면 파일(`.mmdscene`)에 경로만 저장한다.

**실행**: 빌드 폴더의 `MmdStudioPoC.exe`를 실행하면 빈 장면으로 시작한다. 이전 실행이 비정상 종료됐다면 복구할지 먼저 묻는다(8장).

**화면 구성** — 3D 뷰포트가 창 전체를 채우고, 그 위에 흰 카드들이 떠 있다.

| 위치 | 카드 | 하는 일 |
| --- | --- | --- |
| 위 | 상단 도구 모음 | 새로 만들기·열기·최근 장면·저장·다른 이름으로 저장·실행 취소·다시 실행·출력·전체 보기·보기 메뉴·집중 보기·진단 |
| 왼쪽 | 장면 탐색기 | 캐릭터·배경 목록, 환경(조명·카메라·오디오), 캐릭터 추가·배경 추가 버튼 |
| 가운데 | 3D 뷰포트 | 장면 보기, 클릭으로 선택, 기즈모로 배치 |
| 오른쪽 | 속성 창 | 선택한 항목의 설정(변형·모션·재질·조명·카메라·오디오·룩·그래픽) |
| 아래 | 재생 바 | 처음으로·재생/일시정지·정지·타임라인·시간·반복·속도 |
| 맨 아래 | 상태 바 | 진행 상황, 오류, 버튼 설명 |

**카드 숨기기**: 각 카드의 `–` 버튼으로 숨기면 가장자리에 작은 탭이 남고, 탭을 누르면 다시 열린다. 상단 "보기" 메뉴에서도 카드별로 켜고 끌 수 있다.

**집중 보기**: `H`를 누르면 모든 카드가 사라지고 3D 화면만 남는다. `H` 또는 `Esc`, 또는 화면 모서리의 작은 복원 버튼으로 돌아온다.

## 2. 장면 만들기

캐릭터를 넣고 VMD를 연결하면 바로 재생할 수 있다. 배경은 움직이지 않는 PMX다.

1. **캐릭터 추가**(장면 탐색기 아래) → PMX 파일을 고른다. 불러오는 동안 단계가 표시되고, 취소하면 기존 장면은 그대로다.
2. 캐릭터를 선택한 채 속성 창 **모션 → VMD 연결** → 춤 VMD를 고른다. 다른 VMD를 고르면 교체된다.
3. **배경 추가** → 무대·배경 PMX를 고른다. 배경에는 VMD를 연결할 수 없다.
4. 캐릭터를 더 넣으면 1.5 m 간격으로 옆에 놓이고, 각자 다른 VMD를 연결할 수 있다. 모두 같은 장면 시간으로 움직인다.

**선택**: 탐색기에서 누르거나 뷰포트에서 왼쪽 클릭. 빈 곳을 클릭하면 선택이 풀린다. 선택한 항목은 파란 상자로 표시된다.

**배치**

- 속성 창 **변형**에서 위치·회전·크기를 숫자로 입력한다(크기 0.001~1000).
- 뷰포트 기즈모: `W` 이동, `E` 회전, `R` 크기. 축(빨강 X·초록 Y·파랑 Z)을 끌면 그 축만 바뀐다. 크기 모드의 가운데를 끌면 비율을 유지한다.
- **표시** 체크를 끄면 숨겨지고, 탐색기에 "(숨김)"으로 나온다. 숨겨도 모션은 계속 진행된다.
- **선택 보기**(또는 `F`)는 카메라를 그 항목에 맞춘다. 상단 **전체 보기**는 보이는 모든 항목에 맞춘다.

**삭제**: 속성 창 **삭제** 또는 `Delete` → 확인 창에서 한 번 더 누른다. `Ctrl+Z`로 바로 되돌릴 수 있다.

## 3. 재생과 오디오

모든 캐릭터·오디오·카메라 모션은 하나의 장면 시계를 따른다. 장면 길이는 이 중 가장 긴 것이다.

**재생 바**

- ⏮ 처음으로, ▶ 재생/일시정지(`Space`), ■ 정지(처음으로 되돌림).
- 타임라인을 끌면 그 시간으로 이동한다. 오른쪽에 현재/전체 시간이 나온다.
- **반복**: 끝에서 처음으로 돌아간다.
- **속도**: 0.5~2배. 장면 파일에 저장된다.

**오디오(음악) 연결**

1. 장면 탐색기 **환경 → 오디오** 선택.
2. 속성 창 **WAV 연결** → WAV 파일 선택. 장면당 하나다.
3. **음량**(0~100)과 **음소거**를 정한다. **오디오 제거**로 나중에 빼도 `Ctrl+Z`로 되돌릴 수 있다.

- 지원 형식은 **WAV만**(PCM 8/16/24/32비트, float). MP3·OGG·압축 WAV는 안내와 함께 거절된다. 필요하면 다른 프로그램으로 WAV로 변환한다.
- 속도가 1배가 아니면 음높이도 같이 바뀐다. 이때 재생 바에 **음높이 변경** 표시가 나온다.
- 시간 이동은 샘플 단위로 정확하다. 미리보기 재생 중 소리와 화면 차이는 수십 ms 이내다. MP4 출력은 따로 샘플 단위로 맞춘다.

## 4. 카메라

카메라는 직접 조작하거나, 카메라 VMD를 따라가거나, 음악 박자에 맞춰 자동으로 만들 수 있다. 직접 조작이 항상 우선한다.

**뷰포트 조작**

| 동작 | 조작 |
| --- | --- |
| 선택 / 선택 해제 | 왼쪽 버튼 짧게 클릭(빈 곳이면 해제) |
| 회전 | 왼쪽 버튼 드래그(5픽셀 넘게 움직이면 회전, 놓아도 선택은 그대로) |
| 확대·축소(거리) | 오른쪽 버튼 드래그: 위로 밀면 가까이, 아래로 당기면 멀리. 시야각은 그대로 |
| 이동 | 휠 버튼 드래그, 또는 `Shift` + 오른쪽 버튼 드래그 |
| 커서 쪽 확대·축소 | 휠: 커서 아래 모델 표면을 향해 다가간다(표면이 없으면 회전 중심) |
| 선택 항목에 맞추기 | `F` (회전 중심도 다시 잡힌다) |

기즈모 손잡이에서 시작한 왼쪽 드래그는 기즈모가 처리한다. 카드·탭 위에서 누르면 카메라가 움직이지 않고, 뷰포트에서 시작한 드래그는 카드 위를 지나도 이어진다. 다른 창으로 전환하면 드래그가 끝난다.

**시점 저장**: 탐색기 **카메라** → 속성 창에서 시야각(FOV)을 정하고 **현재 시점 저장**. 저장된 시점(최대 16개)을 누르면 그리로 이동한다. **뷰 초기화**는 기본 각도로 돌아가 전체에 맞춘다.

**카메라 VMD**

1. 카메라 속성 창 **카메라 VMD 연결** → 카메라 모션이 든 VMD를 고른다.
2. **카메라 모션 따라가기**가 켜져 있으면 재생·일시정지·시간 이동 모두 VMD 카메라로 본다.
3. 뷰포트에서 카메라를 실제로 움직이거나 `F`·전체 보기·저장 시점을 쓰면 수동 카메라로 바뀐다. 버튼을 눌렀다 놓기만 하거나 모델을 클릭해 고르는 것으로는 바뀌지 않는다. 보이던 위치·방향·시야각·화면 기울기에서 그대로 이어지고, 모션은 장면에 남는다. 다시 따라가기를 켜면 돌아간다. 이어받은 화면 기울기는 카메라 속성 창의 **수평 맞추기**로 없앤다.

모델 추적과 직교 투영은 지원하지 않는다(직교 키는 원근으로 보인다). 캐릭터 모션 VMD처럼 카메라 키가 없는 파일은 거절된다.

**자동 카메라 (박자)** — 오디오가 연결되어 있어야 한다.

1. 카메라 속성 창의 **자동 카메라 (박자)**에서 대상 캐릭터, 컷 간격(1마디 빠름·2마디 보통·4마디 느림), 흔들림(0~1), 시드를 정한다.
2. **박자에 맞춰 카메라 만들기**를 누른다. 곡의 BPM을 찾고, 마디선에서 컷이 바뀌는 카메라 VMD를 만들어 바로 연결한다.
3. 샷은 정면 전신·상반신·클로즈업·느린 궤도 중에서 고른다. 시끄러운 구간일수록 컷이 잦고 가까워진다.
4. 마음에 안 들면 시드를 바꿔 다시 만든다. 같은 설정·시드는 항상 같은 결과다.

만든 VMD는 장면 파일 옆에 `<장면 이름>.autocam-<시드>.vmd`로 저장된다(저장 전이면 앱 폴더). MMD 등에서 열어 직접 고칠 수 있다. 앱 안에서 키를 하나씩 고치는 기능은 아직 없다.

## 5. 룩 꾸미기

가장 빠른 방법은 **룩 프리셋**을 고른 뒤 세부를 조절하는 것이다. 모델은 기본(원본) 재질일 때 조명을 받지 않으므로, 조명 효과를 보려면 재질을 **툰**(배경은 툰·PBR)으로 바꾼다.

**룩 프리셋**(속성 창 항상 표시)

- 기본 4종: 밝은 무대·저녁 실외·어두운 클럽·**밝은 스튜디오**. 조명·그림자·후처리·배경·환경광을 한 번에 바꾸고, 캐릭터 재질을 툰으로 바꾼다. 카메라·초점 대상·효과 품질은 그대로다.
- **밝은 스튜디오**는 밝은 낮 실내 MMD 영상 느낌을 기준으로 만들었다: 밝은 노출, 앞 위에서 오는 부드러운 햇빛, 그림자 쪽을 밝히는 하늘색 환경광, 부드러운 접지 그림자, 약한 Bloom, 조금 낮춘 대비·채도. 캐릭터는 명암이 부드럽게 이어지는 툰과 얇은 윤곽선으로 바뀐다(이 프리셋만 툰 세부 값까지 바꾼다).
- 적용 뒤 값을 바꾸면 "(수정됨)"이 표시되고, **다시 적용**으로 프리셋 값으로 돌아간다.
- 내 프리셋: 이름을 적고 **현재 값을 프리셋으로 저장**(같은 이름이면 덮어씀). **프리셋 삭제**는 내 프리셋만 지운다(장면 값은 유지). 내 프리셋은 앱 설정 폴더에 저장돼 다른 장면에서도 쓸 수 있다.
- 장면에는 프리셋 이름과 실제 값이 같이 저장된다. 나중에 프리셋을 바꿔도 저장한 장면은 변하지 않는다.

**조명**(탐색기 환경 → 조명): 색 R·G·B, 강도(0~8), 수평 방향, 높이, **환경광**(0~2, 0이면 장면 기본)과 환경광 색 R·G·B, 그림자 품질(끄기·낮음·보통·높음). 환경광은 모든 방향에서 오는 채움 빛이라 그림자 쪽이 어둡게 꺼지지 않는다(툰은 '환경광 받기', PBR 배경은 자동으로 받는다). **조명 초기화**는 조명만 기본값으로 돌린다.

**그래픽 효과**(속성 창 그래픽)

| 효과 | 조절 값 | 비고 |
| --- | --- | --- |
| Bloom | 켜기, 강도 | 밝은 부분이 빛난다 |
| 톤매핑 | 켜기 | 밝은 영역을 부드럽게 |
| 노출·대비·채도 | 슬라이더 | |
| 배경색 | R·G·B | |
| SSAO | 켜기, 강도, 반경 | 맞닿는 곳에 그늘 |
| 피사계 심도(DOF) | 켜기, 초점 대상(캐릭터 또는 거리 지정), 초점 거리, 흐림 강도 | 대상을 고르면 그 캐릭터를 계속 따라간다 |
| 비네트 | 켜기, 강도 | 모서리를 어둡게 |
| 효과 품질 | 낮음·보통·높음 | 느린 PC는 낮음 |

**효과 초기화**는 후처리만 되돌리고 카메라·조명·배경·저장 시점은 그대로 둔다.

**재질 스타일**(항목 선택 → 속성 창 재질)

- **원본**: 불러온 그대로(조명 무시).
- **툰**: 명암 경계(켜기·경계 위치·그림자 진하기), **명암 부드러움**(0.01 또렷한 경계 ~ 0.5 부드러운 그라데이션), **환경광 받기**(0~1, 조명의 환경광으로 그림자 쪽을 밝힘), 림 라이트(켜기·강도), 윤곽선(켜기·두께). 윤곽선은 PMX가 윤곽선을 그리는 재질에만 나온다. **모든 캐릭터에 이 툰 설정 적용**으로 한 번에 맞출 수 있다.
- **PBR**(배경만): 매끄러움, 금속성.
- 원본 PMX와 텍스처는 바뀌지 않고, 장면에만 저장된다. 스피어 맵 같은 표시하지 못하는 부분은 "참고"로 알려 준다.

**화면 보정**(캐릭터·배경 선택 → 속성 창 화면 보정)

1. 재생 중 원하는 장면에서 멈추고, 카메라로 고칠 곳에 다가간다.
2. **대상 색 R/G/B·밝기**로 그 캐릭터나 배경 전체의 색과 밝기를 바꾼다.
3. 한 부분만 고치려면 **재질별 보정**을 펼친다. 뷰포트에서 모델을 클릭하면 그 자리의 PMX 재질이 골라진다(목록에서 직접 골라도 된다). 그 재질만 **색·밝기·광택**을 바꾼다.
4. **보정 전 보기**로 같은 카메라·같은 프레임에서 보정 전후를 비교한다. 화면 위에 "보정 전 화면"이 떠 있는 동안은 보정이 꺼진 상태다.
5. **이 재질 보정 초기화**는 고른 재질만, **대상 색·밝기 초기화**는 대상 값만 되돌린다. 바꾼 값은 `Ctrl+Z`로 되돌릴 수 있다.

- 광택은 **툰**(하이라이트)과 **PBR**(매끄러움)에서만 보인다. **원본** 스타일에서는 조명을 받지 않아 광택 칸이 꺼져 있다. 속성 창에 지원 여부와 지금 적용 상태가 나온다.
- 보정은 장면에 저장되고 다시 열면 복원된다. PNG·MP4 출력에도 미리보기와 같은 값이 쓰인다(출력은 "보정 전 보기"와 상관없이 항상 보정을 적용한다).
- 모델 파일이 바뀌어 재질을 확실히 찾을 수 없으면 그 보정은 다른 재질에 적용하지 않고 장면에 보관만 하며, **재질별 보정** 아래에 이유를 보여 준다.

## 6. 물리·신체 흔들림·모션 진단

물리는 캐릭터별로 켜며 기본은 꺼져 있다. 켜면 곡 전체를 미리 계산(굽기)해서 어느 시간으로 이동해도 같은 결과가 나온다.

**물리 (실험)** — 캐릭터 선택 → 모션 섹션

- VMD가 연결된 캐릭터만 켤 수 있다. 머리카락·옷·가슴 등 모델의 모든 강체를 계산한다.
- 켜면 "물리 준비 중 n%"가 표시된다. 준비된 구간까지는 물리로, 나머지는 물리 없이 보인다. 일시정지하면 더 빨리 계산한다. 강체가 많은 모델은 몇 분 걸릴 수 있다.
- 배치를 바꾸거나 VMD를 바꾸면 다시 계산한다.
- **부위별 강도**: 머리카락·치마·옷·가슴·엉덩이·액세서리·기타 슬라이더(0~100%). 다시 계산하지 않고 바로 반영된다.
- "물리가 불안정한 구간"이 표시되면 그 시간에 머리카락·옷이 튈 수 있다. 계산이 실패하면 그 캐릭터만 물리가 꺼지고 이유가 표시된다.

**신체 흔들림** — 가슴·엉덩이 본은 있지만 강체가 없는 모델용

- 끔·약·중·강을 고른다. 해당 본이 없거나 이미 물리 강체가 있는 모델은 고를 수 없다(안내 문구가 이유를 보여 줌).
- **모든 캐릭터에 적용**으로 한 번에 설정한다. 모델 이용 규약을 확인하고 쓴다.

**모션 맞춤 진단** — 모션 섹션 아래에 자동으로 나온다

- VMD가 쓰지만 모델에 없는 본·모프를 알려 준다. 예: "グルーブ 없음 → 몸 전체의 상하 움직임이 빠집니다", "모프 n개 없음 (입 모양 → 립싱크가 빠짐)".
- 머리카락·넥타이처럼 모션 작성자 모델에만 있는 본은 "그 밖의 본"으로 묶인다. 보통 몸 동작에는 영향이 없다.
- 해결 방법은 준표준 본이 추가된 모델을 쓰는 것이다. 앱이 본을 대신 채워 주는 기능은 아직 없다.

## 7. 결과물 출력

상단 도구 모음의 **출력** 버튼으로 PNG 한 장, MP4 동영상, 투명 PNG 시퀀스를 만든다. 출력에는 UI가 들어가지 않고, 창 크기나 PC 속도와 관계없이 같은 결과가 나온다.

1. **출력** → 형식을 고른다.
2. 화면비를 고른다. 사용자 지정은 짝수 크기, 최대 7680×4320이다.
3. MP4·시퀀스는 FPS(60 기본, 30)와 시작·끝(초)을 정한다. 아래에 프레임 수와 예상 시간이 나온다. 60 FPS는 30 FPS의 약 2배가 걸린다.
4. **출력** → 저장할 파일을 고른다. 진행 카드에 "출력 중 n/N · 남은 시간"이 표시되고, **취소**할 수 있다.

| 형식 | 내용 | 비고 |
| --- | --- | --- |
| PNG 이미지 | 현재 장면 시간의 한 장 | 불투명 |
| MP4 동영상 | H.264 영상 + AAC 오디오(장면 오디오가 있으면) | Windows Media Foundation 사용 |
| 투명 PNG 시퀀스 | `이름_000000.png`부터 프레임마다 한 장 | 배경 PMX·배경색 제외, 알파 포함(편집 프로그램에서 합성용) |

| 화면비 프리셋 | 크기 |
| --- | --- |
| 가로 | 1920×1080 |
| 세로 (숏폼 9:16) | 1080×1920 |
| 정사각 | 1080×1080 |

- **안내선**: 세로·정사각을 고르면 뷰포트에 출력 영역이 주황 테두리로 표시되고 바깥은 어둡게 가려진다. `F`·전체 보기도 그 안에 맞춘다. 대화상자의 체크로 끌 수 있다.
- 물리가 켜진 캐릭터가 있으면 물리 계산을 먼저 끝낸 뒤 출력한다. 카메라 VMD를 따라가는 중이면 그 카메라로 출력한다.
- 출력은 재생 속도 설정과 관계없이 **1배속** 장면 시간이다.
- 안전: 완성된 뒤에만 파일이 제자리에 놓인다. 취소하거나 실패하면 만들던 파일은 지워지고, 같은 이름의 기존 파일은 그대로 남는다. 끝나면 장면 시간·카메라·선택이 원래대로 돌아온다.
- 속도 참고(개발 PC, RTX 4090): 1080p60 10초 출력에 약 5초.

## 8. 파일·저장·되돌리기

장면은 `.mmdscene` 파일 하나에 저장된다. PMX·VMD·WAV는 경로만 기록하므로, 원본 파일을 옮기거나 지우면 "누락"으로 표시된다.

| 하고 싶은 일 | 방법 |
| --- | --- |
| 저장 | 상단 저장 또는 `Ctrl+S`. 처음이면 위치를 묻는다 |
| 다른 이름으로 저장 | 상단 다른 이름으로 저장 |
| 열기 | 상단 열기. 불러오는 중에 취소하면 기존 장면이 그대로 남는다 |
| 최근 장면 | 상단 시계 아이콘. 최근 10개, 없는 파일은 "(파일 없음)" 표시·목록에서 지우기 |
| 새 장면 | 상단 새로 만들기 |
| 되돌리기 | `Ctrl+Z` / 다시 하기 `Ctrl+Y`. 최대 200단계 |

- 저장하지 않은 변경이 있으면 제목 뒤에 `*`가 붙고, 열기·새로 만들기·종료 때 저장할지 묻는다.
- 되돌리기 대상: 배치, 표시, 추가·삭제, VMD·WAV·카메라 VMD 연결, 그래픽·조명·룩 프리셋, 재질, 물리 설정, 반복·속도. 파일을 불러오는 것 자체와 카메라 시점 움직임은 대상이 아니다.
- **자동 저장·복구**: 저장 안 한 변경이 있으면 2분마다 별도 복구 파일에 저장한다(원본은 건드리지 않음). 앱이 비정상 종료되면 다음 실행 때 복구·버리기·나중에를 고른다.
- **누락 파일**: 열 때 못 찾은 항목은 목록으로 알려 주고 탐색기에 "(누락)"으로 남는다. 저장해도 사라지지 않는다. PMX는 누락 항목 선택 → **파일 다시 찾기**로 옮겨진 파일을 고르면 배치·설정 그대로 다시 불러온다. VMD·WAV·카메라 VMD는 새 파일을 연결하면 대체된다. 필요 없으면 **장면에서 항목 삭제**.
- **진단**(상단): 버전·PC·장면 요약·최근 오류를 보여 주고 **파일로 내보내기**와 **로그 폴더 열기**를 제공한다. 문제를 물어볼 때 이 파일을 첨부한다. 사용자 폴더 경로는 가려진다.

## 9. 단축키·제한·문제 해결

| 키 | 동작 |
| --- | --- |
| `F11` | 전체 화면 / 창 모드 (상단 **전체 화면** 버튼과 같음, `Alt+Enter`도 됨) |
| `Space` | 재생 / 일시정지 |
| `W` / `E` / `R` | 기즈모 이동 / 회전 / 크기 |
| `F` | 선택 항목에 카메라 맞추기 |
| `H` | 집중 보기 켜기·끄기 |
| `Esc` | 대화상자·삭제 확인 닫기 → 집중 보기 끄기 → 전체 화면 나가기 (이 순서로 하나씩) |
| `Delete` | 선택 항목 삭제(확인 후) |
| `Ctrl+S` | 저장 |
| `Ctrl+Z` / `Ctrl+Y` | 되돌리기 / 다시 하기 |

글자 입력칸에 커서가 있을 때는 `Space`·`Delete`·`W/E/R`이 동작하지 않는다. 뷰포트를 한 번 누르면 다시 된다.

**알려진 제한**

- 오디오는 WAV만 지원한다. 재생 속도를 바꾸면 음높이도 바뀐다.
- "원본" 재질은 조명을 받지 않는다. 툰에서는 스피어 맵이 보이지 않고 주 조명 하나만 쓴다.
- 재질 모프·UV 모프는 재생되지 않는다. 카메라 VMD의 모델 추적·직교 투영은 지원하지 않는다.
- 드래그 앤 드롭으로 파일을 넣을 수 없다. 버튼으로 고른다.
- 창은 가장자리를 끌어 크기를 바꿀 수 있지만, UI가 너무 작아지지 않도록 960×540보다 작게는 줄어들지 않는다.
- 립싱크·VRM 모델·앱 안 카메라 키 편집은 아직 없다.
- 자동 카메라는 4/4박자, 일정한 템포를 가정한다.

**문제 해결**

| 증상 | 해결 |
| --- | --- |
| 조명을 바꿔도 캐릭터가 그대로다 | 재질을 툰으로 바꾼다(또는 룩 프리셋) |
| 열었더니 "(누락)" 항목이 있다 | 원본 파일을 옮기거나 지웠다. 파일 다시 찾기로 연결 |
| 춤의 일부 움직임이 빠진 것 같다 | 모션 맞춤 진단을 본다(준표준 본 없음 등) |
| 물리가 느리다 | 일시정지하면 더 빨리 계산한다. 부위별 강도로 줄이기도 한다 |
| MP4 출력이 "Media Foundation이 필요" 오류 | Windows N 에디션이면 "미디어 기능 팩"을 설치한다 |
| MP4 출력이 "디스크 공간 부족"·"쓰기 권한 없음" | 다른 폴더나 드라이브를 고른다. 기존 파일은 안전하다 |
| WAV를 거절한다 | 압축 WAV일 수 있다. PCM WAV로 변환 |
| 자동 카메라가 "오디오가 필요" | 오디오를 먼저 연결하고 대상 캐릭터를 고른다 |
| 무언가 이상하다 | 상단 진단 → 파일로 내보내기를 첨부해 묻는다 |
