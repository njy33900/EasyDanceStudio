# D-02 오디오 립싱크 — 조사 (P2)

2026-11-22, Claude. 명세 0.5 D-02는 "P2 조사 → P1"이다. 이 문서는 조사 단계의 결과이고, 구현(P1) 착수 여부는 결정 대기다.

## 목표

보컬 오디오에서 모음(あ·い·う·え·お)과 입 닫힘 구간을 추정해 표준 입 모프 키를 만든다.

- 모델에 표준 입 모프가 없으면 경고한다(D-03 진단이 입 모프 수를 이미 센다).
- 기존 VMD에 입 모프 키가 있으면 덮어쓰지 않고 사용자가 고르게 한다.
- 결정 16: 로컬 신호 처리가 우선이고, 외부 서비스와 ML 모델은 쓰지 않는다.

## 방식 비교

| | (a) 음량·포먼트 신호 처리 | (b) 가사 + 타이밍 | (c) 그 밖의 방식 |
|---|---|---|---|
| 내용 | 음량 포락으로 입 열림·닫힘, LPC 포먼트(F1·F2) 또는 MFCC 템플릿으로 모음 | 가나 가사에서 모음 순서를 그대로 얻고, 시각은 보컬 음량의 음절 경계 또는 사용자 표시로 | ML 음소 인식, 보컬 분리 |
| 모음 정확도 | 보컬만 있을 때 높음, **반주가 섞이면 급락**(아래 실측) | 모음 자체는 가사대로 정확, 시각 정렬이 관건 | 높을 수 있음 |
| 처리 시간 | 실시간보다 훨씬 빠름(30 ms 프레임마다 LPC 12차) | (a)의 음량 분할과 같음 | 모델에 따라 큼 |
| 배포 조건 | 자체 코드, 추가 의존성 없음 | 자체 코드, 사용자가 가사 입력 | ML 모델 크기·라이선스, 결정 16과 충돌 |
| 예 | 자체 구현, uLipSync(MIT, MFCC + 모음별 보정 템플릿, Unity) | — | Rhubarb Lip Sync(MIT, 영어 중심), OVRLipSync(독점 라이선스), Spleeter/Demucs(보컬 분리 ML) |

## 실측 — 합성 모음, LPC 포먼트 분류기

- 스크립트: `scripts/research/lipsync_vowel_experiment.py`(표준 라이브러리만 사용).
- 합성 방식: 성대 펄스열 + 공명기 3개로 모음을 만든다.
  - 여성: F0 220 Hz, 일본어 모음 포먼트표 사용.
  - 남성: F0 130 Hz, 포먼트 ×0.85.
- 반주: 화음, 드럼 같은 잡음 버스트, 패드. SNR 단계별로 섞었다.
- 분류: 30 ms 프레임마다 LPC 12차 포락의 봉우리에서 F1·F2를 찾고, 포먼트표의 가장 가까운 모음(로그 거리)으로 분류한다.

| 목소리 | 반주 SNR | あ | い | う | え | お | 평균 |
|---|---|---|---|---|---|---|---|
| 여성 | 없음 | 100 | 100 | 100 | 100 | 94 | **99%** |
| 여성 | 20 dB | 83 | 94 | 94 | 100 | 0 | 74% |
| 여성 | 10 dB | 0 | 61 | 56 | 100 | 0 | 43% |
| 여성 | 0 dB | 0 | 61 | 0 | 78 | 0 | 28% |
| 남성 | 없음 | 89 | 100 | 100 | 100 | 61 | **90%** |
| 남성 | 20 dB | 0 | 89 | 0 | 100 | 0 | 38% |
| 남성 | 10 dB | 0 | 17 | 0 | 72 | 0 | 18% |

- 300프레임 처리에 1.3초(Python). C#이면 실시간보다 훨씬 빠르다.
- **해석**: 반주가 섞인 곡 전체에서는 모음 추정이 쓸모없다. 보컬만 있는 트랙이 사실상 필수다.
  - 반주가 끼면 "え"로 쏠린다. 반주 스펙트럼이 F2 근처 봉우리를 만들기 때문이다.
  - 남성 "お"는 깨끗한 신호에서도 61%다. 고정된 포먼트표의 한계이므로, 화자별 보정(uLipSync 방식)이 필요하다.
- 실제 녹음된 보컬은 시험 자산에 없어 측정하지 않았다. 합성 신호는 실제보다 낙관적이다.

## 제안 (P1 착수 시)

1. **입력**: 보컬만 있는 WAV("보컬 트랙")를 캐릭터에 연결한다. 반주가 섞인 곡만 있으면 **입 열림(あ 크기)만** 음량으로 만들고, 그 한계를 표시한다.
2. **모음**:
   - 첫 버전은 LPC 포먼트 + 곡마다 자동 보정을 쓴다. 보정은 모음 표본 구간의 F1·F2 분포로 화자별 포먼트를 추정한다.
   - 가사(가나)를 입력하면 모음 순서를 가사로 고정하고, 시각만 보컬 음량의 음절 경계에 맞춘다((a)+(b) 혼합).
3. **출력**: あ·い·う·え·お(+입 닫힘)를 캐릭터별 별도 모프 트랙으로 만든다.
   - 재생할 때 모션의 입 모프보다 우선할지는 사용자가 고른다. 기본값은 모션에 입 키가 있으면 모션 우선.
   - 장면에 생성기 버전·입력·설정을 기록한다(명세 5절).
4. **수용 기준(안)**:
   - 사용 허가가 확인된 보컬 녹음에 손으로 붙인 모음 라벨 기준, 프레임 정확도 70% 이상.
   - 입 열림·닫힘 시각 오차 1프레임 이내.
   - 표준 입 모프가 없는 모델에서 경고를 보여 준다.
   - 같은 입력에서 같은 결과가 나온다.

## 결정 대기

- P1 착수 여부, 그리고 "보컬 트랙 필수 + 반주 곡은 입 열림만" 정책.
- 시험용 보컬 음원 확보(사용 허가 포함, 사용자 제공).
